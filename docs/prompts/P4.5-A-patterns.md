# P4.5-A · Pattern Guide v2: colours, motion and the shared patterns

Model: Claude Opus 5.5, High.

Read AGENTS.md, **docs/pattern-guide.md** (all of it), docs/decisions.md (D34, D35, D53, D60–D64), docs/ui-library.md, `packages/ui/src/styles/tokens.css`, `globals.css`, and the installed `drawer`, `responsive-dialog`, `accordion`, `toggle-group`, `number-field`, `save-bar`, `settings-list` and `item` files.

## Goal

Build every pattern in the guide once, in `packages/ui`, so the refit (P4.5-B), Settings (P4-7) and later phases only assemble them.

## Branch

`ag/p45-a-patterns` from the latest main. One PR.

## Build

1. **Colours (D61):** change the light and dark neutral tokens in `tokens.css` to the guide's values. Smart Blue in dark becomes `#7AA5FF` with `#121A2E` text on it. Update `docs/design-tokens.md` and the brand-guard contrast test.
2. **Motion (D62):** add `--dur-press`; give `Button` and interactive rows `active:scale-[0.98]` at that duration.
3. **Sheet:**
   - `ResponsiveDialog` gains `snapPoints` (default half and full on phones), a grabber, a scrollable body with edge fades, a pinned footer above the safe area, and `VirtualKeyboardProvider`.
   - Content stays mounted until the close transition ends.
   - Read the Base UI drawer docs before wiring.
4. **New compositions:** `SegmentedControl` (sliding thumb), `InlineStepper`, `GroupedRows` (or extend `SettingsList`) with value, chevron and switch rows, plus a `RowPickerSheet` (checked list in a sheet).
5. **Chips:** the selected look from the guide (tint, ring, check) in a shared `chip` variant of `Toggle`.
6. **Save pill:** rebuild `SaveBar` as the floating pill on phones and the top-bar actions on desktop, with the change count, spinner and "Saved".
7. **Section nav:** an `EditorSections` composition. Accordion on phones, left list from 1280 px, each header showing a value, content kept mounted, heavy sections loaded on first open.
8. **Kit:** a `/kit?tab=patterns` tab showing every pattern in light and dark, each interactive.

## Not in this task

Changing feature screens (P4.5-B).
